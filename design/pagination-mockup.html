Flow Grid — pagination controls

Static mockups for review. No behaviour is wired; each row is hand-authored to show one state. SLDS ships no pagination blueprint, and its button-group blueprint excludes navigation, so these are custom fgrid-pg-* classes over verified global styling hooks inside a <nav> landmark. Colours, spacing, radii and type all read from hooks, so an org's branding carries through — that is why the numbers are brand-coloured here.

1. Truncation states

My reading of your rule, shown so you can correct it: page 1 gets one ellipsis on the right, the last page gets one on the left, and anywhere in the middle gets both. First and last page numbers are always visible, so total page count is always readable and both ends are one click away.

Accessibility built in

<nav aria-label="Pagination"> landmark; page numbers in a real list; aria-current="page" on the current one, which is also bolded and bordered so colour is never the only signal; disabled plus aria-disabled at the ends; every icon-only button carries slds-assistive-text; the ellipsis is aria-hidden and unfocusable; visible :focus-visible outline on every control.
