Warning threshold — treatment options

Each card is the same component at the same moment. They all switch treatment when the remaining time drops to the threshold, then loop.

Shipped as: these six became four Warning Style values (Color, Color and Weight, Pulse, Tinted Pill) plus three independent toggles — Warning Message, Show Warning Icon and Tint Progress Bar When Warning. So C is "Color and Weight" with a message and the icon; F is style "No Change" with the bar tint. Every combination on this page is reachable, and so are ones that are not.
